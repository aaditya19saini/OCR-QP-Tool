Q.23 Let \(f: \mathbb{R} \to \mathbb{R}\) be a differentiable function so that \(f(x) f'(x) < 0\) for all x. Then, which of the following is necessarily true?

(A) \(f\) is an increasing function

(B) \(f\) is a decreasing function

(C) \(|f|\) is an increasing function

(D) \(|f|\) is a decreasing function

(A) \(M^2 + 3M + 5I = 0\)

(B) \(M^3 - M^2 - 5M = 0\)

(C) \(M^3 - 3M^2 + M = 0\)

(D) \(M^2 - M + 5I = 0\)
