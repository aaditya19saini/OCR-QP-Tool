Q.1 Let X and Y be independent exponentially distributed random variables with means \(1/4\) and \(1/6\) respectively. Let \(Z = \min\{X, Y\}\). Then \(E(Z) =\) ___.

Q.2 Let X be a Geom(0.4) random variable. Then \(P(X = 5 | X \geq 2) =\) ___.

Q.3 X is a single observation from a Bin(\(1, p\)) population, where \(p \in [1/5, 4/5]\) is unknown. If the observed value of X is 0, then the maximum likelihood estimator of p is ___.

Q.4 X is a random variable with density \(f(x) = \frac{1}{4} e^{-|x|^{2}}, -\infty < x < \infty\). Then
\(E(|X|) =\) ___.

Q.5 A system comprising of n identical components works if at least one of the components works. Each of the components works with probability 0.8, independent of all other components. The minimum value of n for which the system works with probability at least 0.97 is ___.

Q.6 Let X be a normal random variable with mean 2 and variance 4, and \(g(a) = P(a \leq X \leq a + 2)\). The value of a that maximizes \(g(a)\) is ___.

Q.7 The volume of the solid formed by revolving the curve y = x between x = 0 and x = 1 about the x-axis is equal to ___.

Q.8 Let [x] be the greatest integer less than or equal to x. Then \(\int_{-1}^{2}[x] dx =\) ___.
