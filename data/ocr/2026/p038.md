Q.39 Let \(Y_1, Y_2\) be a random sample of size 2 from a distribution with the probability mass function
\[f(y) = \left\{ \begin{array}{ll} \theta(1 - \theta)^y, & y = 0, 1, 2, \ldots \\ 0, & \text{otherwise}, \end{array} \right.\)
where \(\theta \in (0, 1)\) is an unknown parameter. Let \(\psi\) be the most powerful
randomized test for testing \(H_0 : \theta = 0.20\) against \(H_1 : \theta = 0.75\) at level 0.05. Which of the following statements is/are true?

(A) The test \(\psi\) rejects \(H_0\) with probability 1 if the observed value of \(Y_1 + Y_2\) is 0

(B) The test \(\psi\) rejects \(H_0\) with probability 1 if the observed value of \(Y_1 + Y_2\) is 1

(C) The test \(\psi\) rejects \(H_0\) with probability \(\frac{5}{16}\) if the observed value of \(Y_1 Y_2\) is 1

(D) The power of the test \(\psi\) is \(\frac{621}{1024}\)
