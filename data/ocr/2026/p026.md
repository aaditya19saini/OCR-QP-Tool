Q.27 Let X be a random sample of size 1 from a \(U(0, \theta)\) distribution, where \(\theta > 0\) is an unknown parameter. To test \(H_0: \theta \geq 1\) against \(H_1: \theta < 1\), the critical region \(X < \frac{3}{4}\) is being used. If \(\beta(\cdot)\) is the power function of the test, then which one of the following statements is NOT true?

(A) The size of the test is \(\frac{3}{4}\)

(B) \(\inf_{\theta < 1} \beta(\theta) = \frac{3}{4}\)

(C) For all \(\theta > 0, \beta(\theta) < 1\)

(D) \(\lim_{\theta \to 0} \beta(\theta) = 1\)
