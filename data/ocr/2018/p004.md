Q.5 Let $X$ be a random variable with the probability density function

\[ f(x) = \begin{cases} \frac{\alpha^p}{\Gamma(p)} e^{-\alpha x} x^{p-1}, & x \geq 0, \alpha > 0, p > 0, \\ 0, & \text{otherwise.} \end{cases} \]

If $E(X) = 20$ and $Var(X) = 10$, then $(\alpha, p)$ is

(A) $(2, 20)$

(B) $(2, 40)$

(C) $(4, 20)$

(D) $(4, 40)$

Q.6 Let $X$ be a random variable with the distribution function

\[ F(x) = \begin{cases} 
0, & x < 0, \\
\frac{1}{4} + \frac{4x - x^2}{8}, & 0 \leq x < 2, \\ 1, & x \geq 2.
\end{cases} \]

Then

\[ P(X = 0) + P(X = 1.5) + P(X = 2) + P(X \geq 1) \]

equals

(A) \(\frac{3}{8}\)

(B) \(\frac{5}{8}\)

(C) \(\frac{7}{8}\)

(D) 1

Q.8 Let $x_1 = 0, x_2 = 1, x_3 = 2, x_4 = 3$ and $x_5 = 0$ be the observed values of a random sample of size 5 from a discrete distribution with the probability mass function

\[ f(x; \theta) = P(X = x) = \begin{cases} \frac{\theta}{3}, & x = 0, \\ \frac{2\theta}{3}, & x = 1, \\ \frac{1 - \theta}{2}, & x = 2, 3, \end{cases} \]

where $\theta \in [0, 1]$ is the unknown parameter. Then the maximum likelihood estimate of $\theta$ is

(A) \(\frac{2}{5}\)

(B) \(\frac{3}{5}\)

(C) \(\frac{5}{7}\)

(D) \(\frac{5}{9}\)
