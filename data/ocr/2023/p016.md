Q.21

Let \((X, Y, Z)\) be a random vector having the joint probability density function

\(f(x, y, z) = \begin{cases} \frac{1}{2xy}, & \text{if } 0 < z < y < x < 1, \\ \frac{1}{2x^2}, & \text{if } 0 < z < x < y < 2x < 2, \\ 0, & \text{otherwise}. \end{cases}\)

Then, which one of the following statements is FALSE?

(A) \(P(Z < Y < X) = \frac{1}{2}\)

(B) \(P(X < Y < Z) = 0\)

(C) \(E(\min\{X, Y\}) = \frac{1}{4}\)

(D) \(Var(Y \mid X) = \frac{1}{2} = \frac{1}{12}\)
