Q.10 Consider the simple linear regression model with $n$ random observations $Y_i = \beta_0 + \beta_1 x_i + \varepsilon_i$, $i = 1, \ldots, n$, $(n > 2)$. $\beta_0$ and $\beta_1$ are unknown parameters, $x_1, \ldots, x_n$ are observed values of the regressor variable and $\varepsilon_1, \ldots, \varepsilon_n$ are error random variables with $E(\varepsilon_i) = 0$, $i = 1, \ldots, n$, and for $i, j = 1, \ldots, n$, $Cov(\varepsilon_i, \varepsilon_j) = \begin{cases} 0, & \text{if } i \neq j, \\ \sigma^2, & \text{if } i = j. \end{cases}$ For real constants $a_1, \ldots, a_n$, if $\sum_{i=1}^{n} a_i Y_i$ is an unbiased estimator of $\beta_1$, then

(A) $\sum_{i=1}^{n} a_i = 0$ and $\sum_{i=1}^{n} a_i x_i = 0$

(B) $\sum_{i=1}^{n} a_i = 0$ and $\sum_{i=1}^{n} a_i x_i = 1$

(C) $\sum_{i=1}^{n} a_i = 1$ and $\sum_{i=1}^{n} a_i x_i = 0$

(D) $\sum_{i=1}^{n} a_i = 1$ and $\sum_{i=1}^{n} a_i x_i = 1$

Q.11 Let $(X, Y)$ have the joint probability density function

$f(x, y) = \begin{cases} \dfrac{1}{2} y^2 e^{-x}, & \text{if } 0 < y < x < \infty, \\ 0, & \text{otherwise.} \end{cases}$

Then $P(Y < 1 \mid X = 3)$ equals

(A) $\dfrac{1}{81}$

(B) $\dfrac{1}{27}$

(C) $\dfrac{1}{9}$

(D) $\dfrac{1}{3}$

Q.12 Let $X_1, X_2, \ldots$ be a sequence of i.i.d. random variables having the probability density function

$f(x) = \begin{cases} \dfrac{1}{B(6, 4)} x^5 (1 - x)^3, & 0 < x < 1, \\ 0, & \text{otherwise.} \end{cases}$

Let $Y_i = \dfrac{X_i}{1 - X_i}$ and $U_n = \dfrac{1}{n} \sum_{i=1}^{n} Y_i$. If the distribution of $\dfrac{\sqrt{n} (U_n - 2)}{\alpha}$ converges to $N(0,1)$ as $n \to \infty$, then a possible value of $\alpha$ is

(A) $\sqrt{7}$

(B) $\sqrt{5}$

(C) $\sqrt{3}$

(D) 1
