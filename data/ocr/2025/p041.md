Q.39
A simple linear regression model \(Y_i = \beta_0 + \beta_1 x_i + \epsilon_i\), with \(x_i = (-1)^i\) for \(i = 1, 2, \ldots, 20\), is fitted. The random error variables \(\epsilon_i\) are uncorrelated with mean 0 and finite variance \(\sigma^2 > 0\). Let \(\hat{\beta}_0\) and \(\hat{\beta}_i\) be the least squares estimators of \(\beta_0\) and \(\beta_i\) respectively. Let \(\hat{Y}_i\) be the fitted value of the \(i^{\text{th}}\) response variable \(Y_i\), for \(i = 1, \ldots, 20\). Which of the following statements is/are correct?

MSQ2

(A) \(\operatorname{Cov}(\hat{\beta}_0, \hat{\beta}_1) = 0\)

(B) \(\operatorname{Var}(\hat{\beta}_0) = \operatorname{Var}(\hat{\beta}_1)\)

(C) \(\operatorname{Var}(\hat{\beta}_0) = \operatorname{Cov}(\hat{Y}_i, \hat{\beta}_0)\) for all \(i = 1, \ldots, 20\)

(D) \(\operatorname{Var}(\hat{\beta}_1) = \operatorname{Cov}(\hat{Y}_i, \hat{\beta}_1)\) for all \(i = 1, \ldots, 20\)
